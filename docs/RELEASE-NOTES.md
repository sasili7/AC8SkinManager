AC8 Skin Manager v0.8.1 — Windows x64, offline single-player campaign only.

- Per-aircraft livery selection and native/MOD coexistence.
- Bilingual desktop importer, installed-livery library and author package builder.
- Read-only on-demand material binding capture, grouped texture slots and record import/export.
- Optional UE4SS setup and AC8OverrideLoader; upstream licenses are included.

The ZIP and EXE are the original release artifacts, not the verification rebuilds. Their SHA256 hashes are in SHA256SUMS.txt. Reviewers can inspect the source, component inventory and build instructions in this repository.

仅用于 Windows x64 离线单机战役。完整 ZIP 内含管理器、桌面工具、可选 UE4SS、AC8OverrideLoader 与许可证；不包含人物涂装资源。安装前阅读包内 README。
