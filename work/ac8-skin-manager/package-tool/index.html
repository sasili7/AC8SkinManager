AC8 LIVERY SYSTEM

使用说明

  1. 玩家：退出游戏，将 .ac8skin.zip 拖入“玩家导入”。
  2. 作者：拖入一个 ZIP，或同名 UTOC／UCAS／PAK 文件。
  3. 作者核对机型、材质槽和按钮信息后生成涂装包。
  4. 进入游戏，在对应机型的 LIVERY 中选择涂装。
  5. “删除”会把涂装移入恢复区；如需撤销，到“已移除”页点击“恢复”。恢复后需要在游戏里重新选择。
  6. 材质读取：安装新版游戏 MOD，离线进入对应机型选机页，选择 STD；在作者页点击“读取当前机体”。也可在游戏按 F7 保存记录后点击“读取保存记录”。选择原贴图自动填写绑定，退出游戏后再打包。记录可导入或导出。
仅用于离线单机；安装或更新前请完全退出游戏。
