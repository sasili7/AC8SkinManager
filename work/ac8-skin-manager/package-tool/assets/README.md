# UI assets

`mascot.png` and `app-icon.jpg` are the project-author-supplied UI illustrations used by the released EXE. They are included so reviewers can reproduce and inspect the application resources. The repository's MIT software license does not grant artwork rights. Third-party artwork remains subject to its own rights; no illustrator identity or license is inferred from the filenames. Independent forks can replace both files with artwork they are permitted to use.
