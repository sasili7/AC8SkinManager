作者制作流程（0.8.1）

1. 完全退出游戏，用本包 Setup.cmd 更新管理器；EXE 直接运行，无需安装 Python。
2. 在 EXE 选择游戏根目录，打开“作者制作”，导入已经完成的单机型纯贴图 ZIP 或同名 UTOC / UCAS / PAK 三件套。
3. 需要获取绑定时，离线启动游戏，停在相同机型的选机页，使用原生涂装；已有 MOD 涂装时先选 STD。
4. 回到 EXE 点击“读取当前机体”。也可在游戏按 F7，回到 EXE 点击“读取保存记录”。
5. 展开“材质与原贴图”，查看槽位编号、材质名称、原贴图和大小写敏感的贴图参数。
   在每张新贴图下选择它替换的原贴图，自动填写对应参数和全部槽位（编号从 0 开始）。
   完整资源路径唯一一致时，只对尚未填写的槽位自动建议；已有包内绑定与手动输入不会被覆盖。
   自定义资源名称需要作者选择原贴图，不能仅凭文件名推断贴图用于哪部分。无法枚举的参数仍可手动填写。
6. 完全退出游戏，填写涂装名、作者及按钮文字和颜色，生成涂装包并点击下载；桌面保存对话框可自行选择位置。
   作者需核对实际绑定和游戏效果后发布。多张贴图不可争用同一槽位的同一个参数。

记录可导入/导出为 .bindings.json，供相同机型、游戏版本及原生材质布局的作者复用。
刷新不会拿旧游戏记录覆盖刚导入的记录。更换游戏版本、机型或原生涂装后重新采集。
采集仅在离线选机页按需执行，不持续扫描材质，不修改飞机材质；飞行或武器选择页面不能采集。
游戏记录目录：Game/Binaries/Win64/ue4ss/Mods/AC8SkinManager/BindingProfiles。
读取超时：确认已更新并重启游戏，MOD 已启用且机型匹配；按 F7 保存，再读取保存记录。
EXE 依赖 Windows WebView2 Runtime 和 .NET Framework 4.6.2 或更高版本。
安装器与游戏 MOD 的前置要求见主 README。绘制工具不在此包内。
